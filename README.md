# Sistema Hospitalario - DevOps

## Descripción

Sistema hospitalario desarrollado como proyecto integrador para aplicar prácticas DevOps.

## Objetivo

Gestionar de manera organizada los procesos básicos de un sistema hospitalario, aplicando control de versiones, ramas, integración continua y despliegue automatizado.

## Tecnologías

- Git
- GitHub
- GitHub Actions
- HTML
- CSS
- JavaScript

## Estructura de ramas

- `main`: versión principal del proyecto.
- `develop`: rama de desarrollo.
- `feature/login`: desarrollo de la funcionalidad de inicio de sesión.
